## Hệ màu (đã có trong `res/values/colors.xml`)

| Tên | Mã | Dùng cho |
|---|---|---|
| `brand_primary` | #1E5EFF | Màu chính, tab đang chọn, link |
| `brand_gradient_start` → `brand_gradient_end` | #2061FF → #3AA1FF | Nút chính (style mặc định của MaterialButton) |
| `bg_screen` | #F4F7FC | Nền các màn sáng |
| `text_primary` / `text_secondary` | #0B2A5B / #6B7A99 | Chữ chính / chữ phụ, nhãn ô nhập |
| `divider` | #E3E7EF | Viền ô nhập, viền thẻ, vạch ngăn |
| `navy_900`, `navy_950`, `navy_700` | #0B2A5A, #061A3B, #133C89 | Nền tối (Splash, Onboarding, màn camera) |
| `accent_cyan` | #3DD6F5 | Khung xương AI, điểm nhấn trên nền tối |
| `state_success` / `state_warning` / `state_error` | #22C55E / #F59E0B / #EF4444 | Đúng / cảnh báo / lỗi |

## Style nút có sẵn (`res/values/styles.xml`)

| Style | Ví dụ trong Figma |
|---|---|
| *(mặc định)* `Widget.AICoach.Button.Primary` | "Đăng nhập", "Bắt đầu tập", "Tạo tài khoản" |
| `Widget.AICoach.Button.Secondary` | "Tiếp tục với Google", "Quay lại đăng nhập", "Huỷ" |
| `Widget.AICoach.Button.Danger` | "Đăng xuất", "Kết thúc" |
| `Widget.AICoach.Button.Text` | "Để sau", "Không, cảm ơn" |
| `Widget.AICoach.Button.OnDark` | Nút phụ trên nền tối |

## Ảnh bài tập

Ảnh người thật (9 bài) cần xuất từ Figma ở **3x, định dạng WebP hoặc PNG**, đặt vào `app/src/main/res/drawable-nodpi/` với tên `img_squat`, `img_pushup`, `img_plank`, `img_lunge`, `img_glute_bridge`, `img_dips`, `img_jumping_jack`, `img_high_knee`, `img_toe_touch`. Thành viên A phụ trách phần này.
